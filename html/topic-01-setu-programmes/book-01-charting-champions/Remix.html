Make it your own

Choose one extension:

Try a pie chart

Change both from pygal import Bar to from pygal import Pie and chart = Bar() to chart = Pie(). Keep the rest of the program. A pie chart shows parts of the data included; our five-country sample is not a complete world medal total.

Chart a class survey

Create survey.csv with anonymous counts, for example:

Football,8
Surfing,5
Cycling,6
Other,4

These are example counts. Replace them with your class’s totals, without collecting names. Load the file and give your chart an accurate title. Compare bar and pie charts: which makes the differences easier to see?

Explain your work

Show a partner your chart and explain the list indexes, loop and number conversion. Save your Python and CSV files together.

Troubleshooting

Problem What to check
ModuleNotFoundError: pygal In Thonny, select local Python 3 and install pygal via Tools → Manage packages.
NameError for Bar Use capital B and import Bar.
FileNotFoundError Run from the folder containing the named CSV file.
IndexError Every nonblank row needs two comma-separated values; indexes are 0 and 1.
ValueError Remove heading rows and thousands separators; use float() for decimals.
IndentationError Use four spaces per level; do not mix tabs and spaces.
Empty or outdated chart Add data before rendering, rerun the program, then refresh the SVG.
No hover or legend interaction The browser/network may block the chart script; use the static chart and labels.

Finished?

You should have a list-based chart, a CSV-based chart, and an explanation of what the data means. Optional worked solutions are available after you have tried the tasks.
