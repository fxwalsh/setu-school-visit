# Charting Champions

Turn numbers into pictures with Python. Create a medal chart, load a CSV file, and investigate what charts can—and cannot—tell us.

## Your challenge

By the end you will be able to:

- Store a name and a number in a Python list.
- Use indexes to retrieve values.
- Create a bar chart with Pygal.
- Read rows from a CSV file using a loop.
- Convert text into numbers and compare charts critically.

Allow 60–75 minutes. Work individually or in pairs. No Raspberry Pi hardware is needed.

This lab adapts the Raspberry Pi Foundation's [Charting champions](https://projects.raspberrypi.org/en/projects/charting-champions/0), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The instructions have been rewritten for a school visit, with local starter files and checkpoints. The medal sample is historical teaching data, **not a current medal table**. Later comparison files are clearly labelled fictional practice data.
