# Create your first chart

Replace the starter code in `main.py` with:

```python
from pygal import Bar

chart = Bar()
chart.title = 'Olympic medals - historical teaching sample'

us = ['United States', 2399]
chart.add(us[0], us[1])

chart.render_to_file('chart.svg')
```

Run the program from the folder containing `main.py`. Open the new `chart.svg` in a web browser. After changing your program, run it again and refresh the browser.

`Bar` is a chart type imported from a library. A library is reusable code written by other programmers. `chart.add()` adds a labelled series, and `render_to_file()` creates the picture.

## Checkpoint

Your chart has one bar, labelled United States, with a value of 2399. Change the title to include your initials and run the code again.

These values come from the original project's historical teaching example. Do not describe them as the latest Olympic totals.
